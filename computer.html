Learn essential computer skills from the beginning.

Lesson 1: Introduction to Computers

A computer is an electronic device that accepts data, processes it, stores it and produces information.

Basic functions

  • Input – Entering data.
  • Processing – Working with data.
  • Output – Displaying results.
  • Storage – Saving information.

Lesson 2: Hardware and Software

Hardware: Physical parts of a computer.

  • Monitor
  • Keyboard
  • Mouse
  • CPU
  • Printer

Software: Programs that tell a computer what to do.

  • Windows
  • Microsoft Word
  • Google Chrome
  • Microsoft Excel

Lesson 3: Operating Systems

An operating system manages computer hardware and software.

Examples

  • Microsoft Windows
  • Linux
  • macOS
  • Android

Lesson 4: Microsoft Word

Microsoft Word is used to create and edit documents.

Common features

  • Typing and editing text
  • Changing fonts and colours
  • Inserting pictures
  • Creating tables
  • Saving and printing documents

Lesson 5: Microsoft Excel

Excel is a spreadsheet program used to organize information and perform calculations.

A1 = 10
A2 = 20
A3 = =SUM(A1:A2)
Result = 30

Excel uses rows, columns and cells.

Lesson 6: Internet and Email

The internet connects computers and devices around the world.

Useful internet activities

  • Searching for information
  • Online learning
  • Sending emails
  • Video meetings
  • Applying for jobs

Email: Electronic mail used to send and receive messages.

Lesson 7: Useful Computer Shortcuts

  • Ctrl + C – Copy
  • Ctrl + V – Paste
  • Ctrl + X – Cut
  • Ctrl + Z – Undo
  • Ctrl + S – Save
  • Ctrl + A – Select All
  • Ctrl + P – Print
  • Alt + Tab – Switch windows
