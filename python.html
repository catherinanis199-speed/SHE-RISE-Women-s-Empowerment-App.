Lesson 2: Variables

Variables are used to store information.

name = "Anu"
age = 20
print(name)
print(age)

Output:

Anu
20

Lesson 3: Data Types

Python has different types of data.

name = "Anu"
age = 20
height = 5.4
is_student = True
  • String: Text
  • Integer: Whole numbers
  • Float: Decimal numbers
  • Boolean: True or False
