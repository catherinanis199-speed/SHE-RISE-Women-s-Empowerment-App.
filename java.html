Lesson 1: Introduction to Java

Java is a popular programming language used for applications, software and enterprise systems.

Java is known for being object-oriented and platform-independent through the Java Virtual Machine (JVM).

Lesson 2: Your First Java Program

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Output:

Hello, World!

System.out.println() displays text on the screen.

Lesson 3: Variables and Data Types

Variables store information in a program.

String name = "Anu";
int age = 20;
double marks = 85.5;
boolean isStudent = true;

System.out.println(name);
System.out.println(age);
  • int – Whole numbers
  • double – Decimal numbers
  • String – Text
  • boolean – True or false

Lesson 4: Operators

Operators perform calculations and comparisons.

int a = 10;
int b = 5;

System.out.println(a + b);
System.out.println(a - b);
System.out.println(a * b);
System.out.println(a / b);

Output: 15, 5, 50, 2

Lesson 5: If-Else Conditions

Conditions help a program make decisions.

int age = 20;

if (age >= 18) {
    System.out.println("You are an adult");
} else {
    System.out.println("You are a minor");
}

Lesson 6: Loops

Loops repeat instructions.

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

Output: 1 2 3 4 5

Lesson 7: Classes and Objects

A class is a blueprint. An object is an instance of a class.

class Student {
    String name = "Anu";
}

public class Main {
    public static void main(String[] args) {
        Student s = new Student();
        System.out.println(s.name);
    }
}
